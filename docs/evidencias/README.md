# Capturas da primeira entrega

Imagens obtidas automaticamente pelos testes Playwright com API e PostgreSQL reais, em 02/11/2026. Contêm somente dados fictícios de teste.

O nome combina navegador, largura em pixels e página: por exemplo, `chrome-360-perfil.png` ou `firefox-1366-conta.png`.

As páginas registradas são `home`, `login`, `area`, `conta` e `perfil`, em Chrome/Firefox e larguras 360/768/1366. A matriz final de seis cenários passou. A descrição dos testes e seus limites está em `../testes.md`.

As contas dessas capturas foram removidas ao final dos testes. Capturas comprovam o estado visual observado; a persistência e as permissões foram verificadas por requisições e testes adicionais.
